# ต้นแบบ: ระดับน้ำเจ้าพระยารายชั่วโมง (5 สถานี)

สถานี: C.2 นครสวรรค์ · C.13 ท้ายเขื่อนเจ้าพระยา · C.3 สิงห์บุรี · C.7A อ่างทอง · C.35 พระนครศรีอยุธยา
แหล่งข้อมูล: SWOC กรมชลประทาน `https://bigdata-swoc.rid.go.th/api/ma/pier/all/get_pier_data`

## ไฟล์
- `collector.py` ดึงค่าล่าสุดของแต่ละสถานี ต่อท้าย `history.json` (ไม่ซ้ำ) เก็บ 48 ชม. (stdlib อย่างเดียว)
- `index.html` หน้ากราฟ: ระดับน้ำ + เส้นตลิ่ง (ประ) + ปริมาณน้ำ (แกนขวา), สลับ 24/48 ชม., เวลาไทย
- `history.json` ข้อมูลเริ่มต้น (ค่าจริง 1 จุดต่อสถานี ยกเว้น C.2 ที่ยังไม่มี)

## วิธีใช้
    python3 collector.py                 # ดึงจริง 1 ครั้ง
    python3 -m http.server 8000          # เปิด http://localhost:8000/ (ต้องผ่านเซิร์ฟเวอร์ ไม่ใช่ดับเบิลคลิกไฟล์)

ตั้งให้รันทุกชั่วโมง (cron):

    5 * * * * cd /path/to/project && python3 collector.py >> collector.log 2>&1

ข้อมูลย้อนหลัง 24–48 ชม. จะ "สะสม" ขึ้นตามเวลาที่ตัวดึงข้อมูลรัน เพราะต้นทางให้ค่าล่าสุดเพียงค่าเดียวต่อสถานี

## ข้อควรรู้
- C.2 ยังไม่เคยเห็นในข้อมูลจริง ตัวดึงข้อมูลจะแจ้งเตือนถ้าไม่พบ และจะเริ่มเก็บเมื่อพบ
- ตอนทดสอบ เวลาล่าสุดของต้นทาง (08:00 น.) ช้ากว่าเวลาที่ดึง (~16:15 น.) ยังไม่ทราบว่าเกิดจากแคชหรือต้นทางอัปเดตช้า หน้าเว็บจะแสดง "เก่า N ชม." เมื่อข้อมูลเก่ากว่า 3 ชม.
- endpoint ไม่มีเอกสารทางการ อาจเปลี่ยนได้ และควรตรวจเงื่อนไขการใช้งานก่อนเผยแพร่สาธารณะ
- เกณฑ์ "ใกล้ตลิ่ง" (ต่ำกว่าตลิ่ง ≤ 0.5 ม.) เป็นเกณฑ์ของต้นแบบเอง ไม่ใช่เกณฑ์เตือนภัยทางการ
